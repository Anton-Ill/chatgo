# Интеграция с Telegram API

## 1. Использование прокси-шлюза
Все запросы к Telegram API должны отправляться через локальный шлюз [`tg-api/index.php`](file:///e:/01_Chatgo/tg-api/index.php).
- URL шлюза берется из константы `TELEGRAM_API_URL` (загружается из `.env`).
- Запросы должны содержать заголовок авторизации с `CHATGO_SECRET`.

## 2. Настройка Webhook
Для регистрации входящих сообщений:
- Webhook должен указывать на обработчик в проекте (например, `webhook-tg.php`).
- При обработке входящих данных из Telegram (объект `Update`), извлекайте `message`, `chat` и `from`.

## 3. Отправка сообщений
Отправка исходящих ответов оператора:
- Метод `sendMessage`.
- Передавать `chat_id` (внешний идентификатор клиента) и `text`.

# Интеграция внешних каналов

## 1. Поддерживаемые типы каналов
Таблица `channels.type` поддерживает:
- `telegram`
- `whatsapp`
- `vk`
- `instagram`
- `max`

## 2. Формат хранения настроек
Поле `channels.settings` должно хранить JSON-строку с учетными данными:
- Telegram: `{"token": "..."}`
- Другие каналы: ключи API, токены доступа, вебхуки, специфичные для каждого провайдера.

## 3. Маршрутизация входящих данных
- Входящие запросы от провайдеров (вебхуки) приводятся к единому формату перед записью в БД.
- Требуемые поля для регистрации чата: `client_external_id` (уникальный ID в сети), `client_name` (имя или никнейм клиента).
